# Nds-WiDaX: Images

This directory contains visual assets (images, diagrams, and maps) created for the **Nds-WiDaX** project.

> ⚠️ **Important**: All images in this directory are licensed under **[Creative Commons Attribution 4.0 International (CC BY 4.0)](LICENSE-CC-BY-4.0)**.  
> This means you are free to use, share, and adapt the images — **as long as you give appropriate credit** to the original creators.

## File Overview

| File | Description |
|------|-------------|
| `graphical_abstract.png` |  PNG version of the graphical abstract showing the five work packages of Nds-WiDaX |
| `graphical_abstract.svg` | Scalable vector version of the graphical abstract |
| `logo_nds_widax.png` | Official logo of the Nds-WiDaX project |
| `map_lower_saxony.png` | Map of Lower Saxony with cities and research data repositories included in Nds-WiDaX |
